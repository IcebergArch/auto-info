# 项目参考

参考内容可选择性使用，不作为强制门禁。

- Apple Human Interface Guidelines：视觉克制、清晰层级、直接操作、系统色与系统字体。
- Apple HIG Layout：相关控件应逻辑分组，保持一致间距，避免输入区域被不必要留白割裂。
- Apple HIG Buttons：触控控件需清晰可辨，周围留白适中；避免按钮尺寸与布局失衡。
- Chrome 首页搜索体验：低干扰中心输入框，历史记录作为辅助入口。
- Material Text Field（dense/normal spacing）：可参考密度策略收紧输入区垂直间距，提升扫描效率。
- 信息报告结构：先给概述，再列事件，最后列参考与审阅状态。
- 图谱表达：节点代表事件，箭头代表影响；颜色表达影响倾向，粗细表达关联强度。
