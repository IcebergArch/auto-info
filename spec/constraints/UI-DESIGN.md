# UI 设计约束（Apple System）

本文件属于 `NORMS.md` 层级；不得违背 `LAW.md`。

## 设计原则

1. **克制**：少边框、多留白；避免过重装饰与高密度信息墙。
2. **层次**：用字重、字号、灰度与轻阴影区分层级，而非粗线条。
3. **一致**：全站复用设计令牌（`apps/web-react/src/styles/app.css` 的 `:root`）。
4. **可读**：正文行高约 1.47；全站 `letter-spacing` 保持 `0`，避免在响应式容器中挤压文字。
5. **自适应**：页面宽高、报告、图谱与表单必须在桌面/窄屏下自然缩放，不出现文本挤压或交互控件重叠。
6. **视口铺满**：`#root` → `.app` → `.app-body` → 当前页 `.panel` 须形成 `flex:1; min-height:0` 高度链，主面板白底铺满顶栏以下区域，禁止在页面底部露出大块灰色空白；内容超出时在面板内滚动。
7. **苹果风格优先**：默认遵循 Apple 式简洁与优雅，弱化装饰性视觉，突出内容与操作本身。
8. **经典布局优先**：优先采用稳定信息架构（如三列式：主内容 + 辅助信息 + 操作区），并保持主次分明。
9. **用户触发优先**：所有页面以用户任务触发点为核心，先满足主任务路径，再展示扩展信息。
10. **极简交互优先**：默认采用“输入框 + 主按钮”作为首屏交互骨架，附加信息按需延后展示。

## 组件规范

- **顶栏**：毛玻璃 `backdrop-filter` + 浅底；导航为胶囊分段控件。
- **移动端顶栏**：导航按钮必须 `nowrap`，使用横向滚动承载溢出；禁止把「首页 / 科技雷达」等 Tab 文案拆成单字换行。
- **主按钮**：填充 `--accent`，圆角 pill，`font-weight: 600`。
- **次按钮**：白底 + 细边框，hover 仅轻微背景变化。
- **阅读助手操作按钮**：禁止“视觉过大”。推荐高度 `34-36px`、字体 `13-14px`、水平内边距 `12-16px`。
- **按钮拉伸约束**：按钮默认按内容宽度展示，不得被拉伸为整行长条；仅在移动端明确需要“整行主操作”时允许 `width: 100%`。
- **输入分组间距约束**：阅读助手中“标签-输入框”必须紧凑分组。推荐标签与输入间距 `4-8px`，字段组之间间距 `10-14px`，禁止出现明显割裂的大间隙。
- **卡片**：白底 + `--shadow-soft`；避免左侧粗色条（除必要状态）。
- **标签**：小圆角 pill，浅色底 + accent 字色。
- **日报**：`概要` + 四块正文（**国际局势** · **科技** · **金融** · **其他**）+ **参考**；无「感兴趣方面」「关键事件」独立段；「其他」块展示域说明（医疗/旅行/中国生活/媒体热点）；概要速览条仅四向标签；事件卡片主标题为中文 `displayTitle`，英文原标题作副标题。
- **首页**：搜索区 `home-search-block` **固定高度、不参与 flex 拉伸**（报告展开/收起不得导致输入区变形）；主区 `home-report-view` 滚动承载日报；右侧栏**仅筛选日期/归档列表**，禁止在侧栏再嵌一份报告正文；「历史日报补齐」属于低频批处理能力，默认收纳为侧栏小按钮，点击后用弹窗承载按天数/按月/长区间等配置与结果，避免长期占用界面资源；报告统一用 `DailyReportCard` + `report-document` 展开模块，**点击标题**展开/收起。
- **统一报告版式**：`report-document` + `ReportSection`（日报、阅读简报、分析明细共用）；原则：清晰层级、低阅读成本、留白克制；事件/时间线条目：**标题为纯文本**（不可点击），**概述**（`desc`）紧跟标题下方；**仅** `SourceJumpLink`（↗）跳转来源。今日日报时间线：`EventTimeline` — 垂直 Card 列表 + 左侧 timeline connector（圆点/竖线），复用 `report-event-card` 视觉。
- **首页/日报**：概要总览下 **国际局势 · 科技 · 金融** 三栏 `report-overview-panels`（**1:1:1** 水平、等高拉伸、栏内要点垂直排列，矮栏底部留白）；`概要` 首段（`report-lead`）须使用与正文卡片区分的轻底色摘要块（内边距 `12-14px`、圆角 `10-12px`、行高 ≥ `1.6`），避免整段文字直接贴边导致阅读压迫；今日日报 `时间线` 区须显式展示“上次刷新时间 + 最新事件时间 + 是否超过计划刷新时间/暂无新增事件”，禁止只给时间轴区间让用户自行猜测“未刷新还是无新事件”；`report-event-card` 白底轻阴影；`daily-card` 白底 + `--shadow-soft`。
- **图谱 / 分析关联**：事件线时间轴 + 影响关系**文字列表**（`→` + 说明）；禁止用线条粗细表达强度；关联图禁止 ReactFlow 缩放式主视图。
- **交互层次**：默认简洁展示，点击展开明细（渐进披露），避免默认铺开全部信息。
- **图标优先原则**：对“刷新、关闭、展开/收起、返回、更多”等高频通用动作，优先使用清晰图标；仅在语义不明确时追加短文本。
- **回车执行**：输入框所在表单必须支持 Enter 直接提交（在不破坏可读性的前提下减少额外点击）。
- **产品工作台头部**：首页、分析、阅读助手、科技雷达等主任务页须在 `h2` 下方提供统一 `workspace-hero`：左侧为任务定位与一句话说明，右侧为状态胶囊/主操作；页面内再用 `workspace-focus-strip` 承载 2-4 个短状态，避免用户进入页面后只能看到裸输入框或长列表。
- **阅读助手结果区**：`ReadingBriefDocument` 固定三节 **摘要 · 要点 · 建议**（**全部简体中文**）；三节**默认均展开**（与摘要一致）；「原文来源」默认折叠，保留英文 URL/标题 + ↗；外层可整体展开/收起。
- **阅读助手布局**：与首页一致 **8:2 左右分栏**（`reading-grid`）；左侧主区 `reading-main` 固定输入 + 可滚动简报（`reading-report-view`）；右侧 `reading-history` **仅历史列表**，点击回填主区；禁止在侧栏重复展示简报正文；交互同首页（侧栏选历史、主区看内容、标题点击展开/收起）；**进入页自动恢复最近一条 LRU 简报**；重复 URL/正文 upsert 置顶，不重复堆叠历史。
- **分析页布局**：与阅读助手一致 **8:2**（`analysis-grid`）；右侧历史列表；脉络图右上角 **更新事件**；进入页恢复最近一条分析。
- **分析页脉络**：`EventLinesChart` 展示 `axisNarrative`（背景讲述 + 事件起止轴标签），非固定回溯窗口日期；主事件轴 + 影响域 + 外溢箭头；时间坐标必须消费 `eventLines.timeAxis`，采用 **近细远粗** 的非等比例映射，节点、箭头、年份刻度、`EventLinesTimeBrush` 与滚轮缩放共用同一 scale；**点击**圆点或节点列表展示事件明细；图表右侧阅读留白；`EventLinesTimeBrush` 时间条 + 滚轮缩放（类 F12 Network 区间筛选）；横向密集点 **聚类选中**（角标数量 + 多卡片明细 + 列表联动高亮）。
- **分析页主视图**（UC-002）：不再展示 `AnalysisLayeredStack` 的“概览 / 地区关联列表 / 维度图层”前置模块；分析结果优先进入 `EventLinesChart` 主可视化与下方跨线影响文字列表，避免主任务前出现低价值统计面板。
- **分析页图文邻近**（以用户为中心）：说明文字与操作按钮/箭头符号**不得**因 `flex-wrap` 折到同一行粘连；工具栏叙事与「更新事件」分列；时间刷选条「区间说明」与「重置」分列，操作提示独立一行。图表内泳道名 **右对齐贴齐该泳道轴线左端**（`text-anchor: end`），禁止堆在画布最左侧导致「A 泳道文字像 B 泳道」；外溢箭头说明 **锚在箭头落点（目标泳道）旁**，完整句优先在下方「跨线影响」列表阅读。关联行：箭头列固定宽度 + 正文列，图标与文字间距 ≥ `10px`，`nowrap` 保持同条语义一体。
- **首页侧栏**：置顶「今日日报」；历史为 `日期 · 名称`。
- **快捷访问**：左右分栏 **2:8**；左栏 URL 目录；右栏**启动器**（当前 URL、在新窗口打开、复制链接），**禁止 iframe 页内预览**；点击目录或添加后 `window.open` 打开原始 URL；本地 URL 默认 `http://`。
- **配置页**：与其它页一致使用 `panel` + 顶栏 `h2` + `result-text` 说明；链路状态置于 `config-block`；每项可打开弹窗查看/编辑配置详情（敏感字段掩码，保存走 `PUT /api/v1/config`）。
- **科技雷达**（UC-006）：**8:2** 布局；左栏可滚动。刷新周期与首页报告一致，默认 **1h**；当日条目显示 `HH:mm`，非当日内容显示到日期粒度。分区**禁止长段说明**；全局范围仅在 `ReportSection` 标题旁展示，月份节点只展示月份与数量，不再重复展示整月日期区间；日级内容必须收纳为同一天的卡片组（如 `6.01` 组内多条卡片），不得把日期、类型、标题拆成松散列表；折叠区使用柔和圆角、浅背景、轻阴影与平滑展开动效，避免硬边框树状控件。空列表用 `—`。后续 Figma/页面迭代须保持「范围 + 卡片组」、不恢复导语式文案。

## 猎户座（Orion）品牌

- **体系**：Auto Info 为猎户座 Nexus 子产品；浏览器 **title** 默认 `Auto Info · 猎户座`，非首页 Tab 为 `{页面} · Auto Info · 猎户座`（`useDocumentTitle`）。
- **图标语言**：圆角方底 + **三颗星带**（猎户座腰带）+ 右上 **信标点**（Auto Info 情报/雷达子标识）；色值 `#0071e3` / `#ffffff` / `#b8dcff`，与 `--accent` 一致。
- **静态资源**：`apps/web-react/public/favicon.svg`、`apple-touch-icon.svg`；`index.html` 声明 `icon` / `apple-touch-icon` / `theme-color`。
- **顶栏**：左侧 `AppBrand`（图标 + `Auto Info` + `猎户座 Orion`）可点回首页；中部 Tab 导航保持居中（`topbar` 三列网格 + 右侧隐形占位平衡）。

## 禁止

- 大面积高饱和渐变背景
- 全大写 eyebrow + 过粗字重（800+）作为主视觉
- 与令牌不一致的随意 hex 色（除非新增令牌）
- 首页堆叠热点榜、信息卡墙或与搜索无关的复杂内容
- 首页直接展开完整日报正文（应通过点击进入日报单页）
- 快捷访问页使用 iframe 嵌入外部站点（登录态不完整、禁止作为主路径）

## 文件范围

- `apps/web-react/**` — 唯一前端（页面、组件、样式、设计令牌）

## 设计审查门禁（强制）

所有 UI 变更（布局、样式、组件、交互）在交付前必须通过 **Design Agent 审查**：

1. 审查输入：变更页面、组件截图/描述、与对应 UC 或约束链接
2. 审查维度：一致性、可读性、层级、任务主路径、响应式
3. 审查结果：`通过` 或 `驳回（附修正项）`
4. 未通过审查不得宣称完成

### 审查补充（防止“走过场”）

- 审查必须包含**按钮与核心交互控件**的视觉检查（尺寸、圆角、字重、状态、对比度）。
- 审查必须包含桌面与窄屏双视口检查，确认控件不会出现异常拉伸或挤压。
- 审查结论必须附最少一条“已检查证据”（截图描述或可复现页面路径）。
- 若出现“视觉明显不协调/不美观”反馈，默认判定为驳回并进入修正轮。
