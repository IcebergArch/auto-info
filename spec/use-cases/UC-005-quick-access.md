# UC-005：快捷访问页（URL 工作台）

**Implements:** REQ-F-005  
**Actors:** 用户（主）、Web 前端（次）  
**Preconditions:** 页面已加载  
**Postconditions:** 用户可管理 URL 目录并在**新窗口**打开完整站点（非 iframe）

## 触发

用户点击 top-bar 的「快捷访问」标签页。

## 主流程

1. 用户进入快捷访问页。
2. 用户在输入框填写 URL 并提交（或 Enter）。
3. 前端校验并规范化 URL（本地 `localhost` / `host:port` 默认 `http://`，其它默认 `https://`）。
4. 前端将 URL 写入左侧历史列表（去重，最近访问优先）。
5. 用户点击左侧目录项或「在新窗口打开」：**在新标签页打开原始 URL**（`window.open`，完整 Cookie / 登录态）。
6. 右侧为**启动器**（显示当前 URL、打开、复制），不提供页内 iframe 预览。

## 布局（强制）

- 页面采用 **左右分栏 2:8**（`grid-template-columns: 2fr 8fr`）。
- **左侧（2）**：URL 输入 + 纵向目录；每项可点击打开、↗ 快捷打开、移除。
- **右侧（8）**：当前链接启动器（标题、完整 URL、主按钮「在新窗口打开」、复制链接、说明文案）。
- **禁止**右侧 iframe 嵌入预览（见规则 §为何不用 iframe）。

## 规则

1. URL 历史必须去重（同一 URL 不重复追加，仅提升到顶部）。
2. 历史记录持久化在 `localStorage`（`quick-access-history`），刷新后可恢复。
3. 弹窗被拦截时须提示用户使用主按钮或复制链接。
4. 默认种子链接可为 `http://localhost:7474/browser/`（Neo4j），但须通过新窗口打开，不经 embed 代理。

## 为何不用 iframe（强制）

以下原因导致页内预览不可作为交付目标，不得再回归 iframe 主路径：

| 原因 | 说明 |
|------|------|
| X-Frame-Options / CSP | 多数管理台禁止被嵌入 |
| 登录 / SSO | 代理或 iframe 内会话与直接访问不一致，易出现登录页 |
| SPA 资源路径 | HTML 改写后 JS/CSS/WS 仍可能指向错误源 |
| 体验目标 | 用户需要与系统浏览器一致的完整站点 |

后端 embed 代理（`/api/v1/quick-access/embed/`、`/neo4j`）仅保留供兼容或调试，**快捷访问页不得依赖**。

## 异常流

### EXC-1：URL 非法

- **触发：** 用户输入无法解析为合法 URL  
- **响应：** 前端提示错误，不写入历史，不尝试打开

### EXC-2：弹窗拦截

- **触发：** `window.open` 返回 `null`  
- **响应：** 展示 `actionHint`，引导用户点击「在新窗口打开」或复制链接
